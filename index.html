HTML Forms: All Input Types

This page demonstrates every HTML input type for first-year IT students. Each field includes a short description and a link to the W3Schools documentation.

text

Single-line text field for general text input. W3Schools: type="text"

password

Masks characters as they are typed; use for secrets like passwords. W3Schools: type="password"

email

Optimized for email addresses; browsers can validate the format. W3Schools: type="email"

number

Numeric input with optional min, max, and step; often shows spinner controls. W3Schools: type="number"

tel

For telephone numbers; on mobile devices it often opens a phone keypad. W3Schools: type="tel"

url

For web addresses; browsers can check that the value looks like a URL. W3Schools: type="url"

search

Styled as a search field; some browsers add a clear (×) button. W3Schools: type="search"

date

Date picker for year, month, and day (no time). W3Schools: type="date"

time

Time picker for hours and minutes (and sometimes seconds). W3Schools: type="time"

datetime-local

Combined date and time picker without a time zone. W3Schools: type="datetime-local"

month

Selects a month and year only (no specific day). W3Schools: type="month"

week

Selects a week number within a year. W3Schools: type="week"

color

Opens a color picker; value is a hex color such as #ff0000. W3Schools: type="color"

range

Slider control for a numeric value within a range. W3Schools: type="range"

file

Lets the user choose one or more files from their device. W3Schools: type="file"

checkbox

On/off choice; several checkboxes can be selected at once. W3Schools: type="checkbox"

radio

Mutually exclusive options in a group that share the same name. W3Schools: type="radio"

hidden

Not shown on the page, but still submitted with the form (e.g. IDs or tokens). W3Schools: type="hidden"

This field is invisible — inspect the page source to see it.

button

A clickable button with no default form action (usually handled with JavaScript). W3Schools: type="button"

reset

Resets all form fields back to their initial values. W3Schools: type="reset"

submit

Submits the form to the URL in the form’s action attribute. W3Schools: type="submit"
