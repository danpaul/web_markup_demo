CSS Positioning

The five position values change whether a box stays in document flow, which ancestor it is measured from, and how it reacts to scrolling. This page does not print the important numbers. Open your inspector and read them from css/style.css.

Use the inspector first

Every demo box on this page is styled only from the stylesheet. Right-click a box, choose Inspect, and read the position, offset, and z-index rules in the Styles pane. The Computed pane shows the used values after the cascade.

  1. Press Ctrl + Shift + C (Cmd + Option + C on macOS) and click a labeled box.
  2. In Styles, find position. Hover the property to see the box overlay in the page.
  3. Check top, right, bottom, left, and z-index. If a rule looks unused, that is a clue — static boxes ignore offsets.
  4. Open Sources and open css/style.css to see the same rules in context, including the lab comments.

Absolute — leave the flow

An absolutely positioned box is removed from flow, so siblings close the gap. Offsets are measured from the nearest positioned ancestor (anything except static). If every ancestor is static, it uses the initial containing block.

Fixed — pin to the viewport

Fixed boxes leave the flow and are positioned against the viewport. They stay on screen while the document scrolls. The inspector tip along the bottom of this page is already fixed — inspect that aside before you toggle the banner below.

Sticky — in flow, then cling

Sticky is a hybrid. The box stays in flow until it hits a threshold (top is the usual one), then it sticks inside its scroll ancestor. The section navigation at the top of this page is sticky — inspect it, then scroll this inner scroller.

Inspector challenges

Answer from DevTools, then open the solution. Guessing from the HTML will not work — the values live in the CSS file.

  1. What position value is used on the section navigation?

    Reveal after inspecting

    The nav is sticky. That is why it clings to the top of the viewport while remaining in the document flow.

  2. With offsets applied, what are the top and left values on relative box B?

    Reveal after inspecting

    Look at .relative-box in the stylesheet for both offsets.

  3. Which element is the containing block for the banana caption? What are its top and right offsets?

    Reveal after inspecting

    The figure.photo-frame is positioned, so it contains the absolute figcaption. Read the offsets from .photo-badge.

  4. What z-index does the front stacking card use, and why does the static card ignore its own z-index?

    Reveal after inspecting

    The front card is positioned, so its z-index counts. The gray card is static, so its z-index has no effect.

  5. What top value makes the chapter headings stick inside the inner scroller?

    Reveal after inspecting

    Inspect any h3 inside .sticky-scroller.

Quick map

Use this table after you have inspected the demos. It is a memory aid, not a substitute for reading the computed styles.

Value In flow? Offsets measured from On scroll
static Yes Ignored Scrolls with the document
relative Yes (original space kept) The box’s own starting position Scrolls with the document
absolute No Nearest positioned ancestor Scrolls with that ancestor
fixed No The viewport Stays on screen
sticky Yes, until the threshold The nearest scroll ancestor Clings until the ancestor ends
